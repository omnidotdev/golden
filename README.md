**The canonical baseline for how Omni code should look, behave, and be styled.**

**Golden** documents Omni's style conventions, architectural patterns, and agent rules. It's the source of truth for _how_ code should be written across the ecosystem.

For config files and project scaffolding (e.g. `tsconfig.json`, `Cargo.toml`), see [Omni Templates](https://docs.omni.dev/realms/armory/templates).

## Philosophy

Omni believes in **clarity through consistency**. Boilerplate tooling and style should get out of the way, allowing creators and developers to move fast without losing precision. Golden embodies this principle: a single baseline, shared by all.
